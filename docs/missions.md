# Vos missions

C'est bon, vous êtes expert du projet ?

- Pour configurer le projet, [c'est ici](setup.md)
- Pour découvrir la spécification du projet, [c'est ici](spec.md)

Pendant ce workshop, plusieurs missions sont réalisables. Vous n'aurez probablement pas le temps de toutes les faire.

Chaque mission est indépendante et traite d'un sujet en particulier. Vous pouvez commencer par celle que vous voulez !

[**Focus sur le langage Kotlin**](mission-euro.md) (value class, opérateurs, tests) : ajoutons des vérifications de type aux sommes d'argent.

[**Focus sur le backend**](mission-backend.md) (Ktor, MongoDB) : ajoutons des nouvelles fonctionnalités à l'application.

**Focus sur la performance** (OpenTelemetry, Coroutines) : analysons la performance de l'application.
